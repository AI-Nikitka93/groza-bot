## 1. WEB RESEARCH (Паттерны метеорадаров)

### Визуализация плотности молний
- **Hex Grid Density (Гексагональный биннинг):** Замена единичных точек на тепловую гексагональную сетку при высокой плотности ударов.
- **Opacity & Size Decay (Возрастной градиент):** Свежие удары — крупные точки (100% opacity), старые (до 30 мин) — мелкие (20-30% opacity).

### Направление движения фронта (Статика)
- **Изохронные векторы (SCIT):** Линия со стрелкой из ядра шторма с таймстампами ("+15m", "+30m").
- **Motion Blurred Heat Trails:** Хвост фронта размывается градиентом затухания, четкий фронт спереди.

### Контрастность и слои
- **Muted Basemaps:** Обесцвеченная темная подложка (charcoal/dark navy). 
- **Double Contour (Двойной контур):** Белое ядро маркера + неоновое свечение + жесткая черная тень (drop-shadow) для 100% читаемости на солнце.

## 2. GITHUB RESEARCH (Опенсорсные ГИС и Боты)

### Статические генераторы (Backend, Python/Node.js)
Для рассылки картинок без клиентского рендера и затрат на API:
- **Python:** `flopp/py-staticmaps` (поддержка PNG/SVG, anti-aliasing через pycairo) или `komoot/staticmap`.
- **Node.js:** `StephanGeorg/staticmaps` (рендеринг через библиотеку `sharp`).
*Важно:* Использовать бесплатные тайлы OSM, при росте нагрузки — поднять свой OpenMapTiles.

### Интерактивные карты в Telegram WebApp (TMA)
- **Стек:** `MapLibre GL JS` (WebGL векторные тайлы, 60 FPS).
- **Интеграция:** Нативный вызов `LocationManager` через Telegram API. Поддержка `themeParams` для смены Day/Night режима. Учет `safeAreaInset` для UI-элементов под "челку".

## 3. PAPERS LANE (Психология предупреждений)

### Цветовая психология (HEX) и Когнитивная нагрузка
Разработка для улицы (солнце, блики) в Dark Mode требует сверхконтраста. Чистый красный математически не может достичь WCAG AAA (7:1) на темном фоне. Обоснованный выбор неоновых пар (на базовом фоне `#0C0D10` — сланцево-черный, поглощающий блики):
- **Critical (5 км): `#FF7575` (Neon Coral Red) или `#FF7B00` (Safety Neon Orange)**. Конкретное восприятие. Привлекают внимание, но не режут глаза. Контрастность на фоне `#0C0D10` составляет ~7.4:1 (Строгий WCAG AAA).
- **Warning (15 км): `#FFEA00` (Cyber Neon Yellow)**. Создает осознанность (awareness). Контрастность на фоне `#0C0D10` составляет **15.6 : 1**, что дает идеальную читаемость под ярким солнцем и снижает "Warning Fatigue".
- **Правило ореола (Halo):** Обязательно добавлять вокруг сигнального текста обводку цвета фона (`#0C0D10`) в 2-3 px, чтобы избежать слияния полигонов карты и текста. Начертания шрифтов не ниже SemiBold.

### Тексты: "Перевернутая пирамида" (NN/g)
В стрессе рабочая память падает до 3-4 элементов. 
1. **Главное (Lead):** Каков следующий шаг? [Угроза] + [Действие СЕЙЧАС].
2. **Детали (Supporting):** Локализация. [Дистанция] + [Время].
3. **Фон (Background):** Ссылка на карту. Progressive Disclosure.
*Пример:* "⚠️ Молния в 5 км. Немедленно зайдите в помещение. Грозовой фронт будет над вами через 15 мин. [Открыть карту]"

### Калибровка доверия (Trust Calibration)
- **Вероятностное фреймирование:** Отказ от абсолютных заявлений ("Ударит молния") в пользу вероятностей ("Высокая опасность").
- **Замыкающее сообщение (Downgrade/Отбой):** Обязательное объяснение ложноположительного срабатывания: *"🌤️ Грозовой фронт сместился. Угроза миновала. Предупреждение снято."*
- **Feedback Loop:** Кнопки под алертом: *"Оправдался ли прогноз? [Да] / [Нет]"* — возвращает контроль пользователю и помогает алгоритму.

## 4. UX REQUIREMENTS (Требования к интерфейсу)

### Frictionless Onboarding Schema
1. **Экран 1:** Приветствие с главным Value Proposition (Ваш личный радар).
2. **Экран 2:** Явный запрос геолокации через нативную кнопку Telegram (Share Location) с объяснением: "Где вы находитесь, чтобы бот охранял ваш 15км радиус?".
3. **Экран 3:** Подтверждение активации радара с тестовым silent-сообщением для демонстрации.

### Формат статической карты предупреждения
- **Стиль:** Dark Mode (charcoal/navy OSM tiles).
- **Слои:** Ядро (Hex grid) + Вектор движения (SCIT со стрелкой) + Маркер пользователя с белой окантовкой.
- **Размер:** Оптимально 800x600 px для быстрой загрузки.
