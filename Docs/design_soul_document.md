# DESIGN SOUL DOCUMENT: Personal Pocket Lightning Rod (Groza Bot)

## INSPIRATION BOARD
Анализ 15 визуальных референсов из авиации, тактических систем и профессиональных метеорадаров.

### Aviation & Tactical Interfaces
1. **Garmin G1000 Weather Radar (NEXRAD):** Черный фон с жесткими красными/пурпурными полигонами для грозовых ячеек. *Заимствуем: Утилитарность и отсутствие отвлекающих элементов. Эмоция: Профессиональная собранность.*
2. **Boeing 787 Navigation Display (ND):** Тонкие неоновые векторы (зеленый/белый) поверх абсолютно черного фона. *Заимствуем: Моноширинные цифры дистанций и компасные насечки. Эмоция: Безопасность.*
3. **Lockheed Martin F-35 Tactical Display:** Гексагональные сетки (Hex Grids) для отображения плотности целей. *Заимствуем: Биннинг вместо спагетти из точек. Эмоция: Технологичность.*
4. **Palantir Gotham UI:** Высокий контраст, использование неонового оранжевого и красного для маркировки угроз. *Заимствуем: Свечение маркеров (Halo-эффект). Эмоция: Уверенный контроль.*
5. **ATAK (Android Team Awareness Kit):** Милитари-интерфейс, крупные контрастные кнопки с иконками для работы в перчатках. *Заимствуем: Крупную геометрию элементов Onboarding'а.*

### Professional Weather & GIS
6. **RadarScope Pro (Dark Mode):** Индикатор Storm Cell Identification and Tracking (SCIT) — белые векторы с засечками таймстампов. *Заимствуем: Визуализацию движения фронта.*
7. **LightningMaps.org (Dark Map):** Индикация стареющих молний градиентом размера и прозрачности. *Заимствуем: Opacity decay паттерн.*
8. **Windy (Thunderstorm Layer):** Тонкие линии стримлайнов ветра на темном полотне. *Заимствуем: Минимализм фоновой подложки.*
9. **Dark Sky (Legacy UI):** Черно-белая типографика с акцентным цветом осадков. *Заимствуем: Жесткую иерархию (сначала действие, потом детали).*
10. **Mapbox Dark UI Template:** Сланцево-черный фон `#0C0D10` с приглушенными дорогами. *Заимствуем: Когнитивное наслаивание, где карта вторична.*

### Dribbble/Mobbin Extreme UI Patterns
11. **Mobbin - Strava (Dark Mode Maps):** Ультра-контрастные неоновые маршруты на темной OSM-карте. *Заимствуем: Свечение неоновых линий.*
12. **Behance - "Cyberpunk Smart City Dashboard":** Использование шрифтов типа JetBrains Mono для всех телеметрических данных. *Заимствуем: Моноширинность цифр для читаемости на бегу.*
13. **Dribbble - "Emergency Response HUD":** Красные (`#FF7575`) плашки Alert с черным текстом внутри. *Заимствуем: Инверсию цвета для Critical Warning.*
14. **Mobbin - Tesla App (Climate/Car Status):** Фотореалистичный или жесткий 3D/2D рендер объекта с минимумом текста. *Заимствуем: Одинокий локус контроля.*
15. **Behance - "Dark Mode Weather App Concept":** Жесткие тени (Drop Shadows) под яркими элементами на темном фоне. *Заимствуем: Эффект левитации маркеров над картой.*

## GITHUB DESIGN SCAN
- **Иконки:** [Lucide Icons](https://lucide.dev/) (лицензия ISC, абсолютно бесплатно). Используем строгие геометрические контуры молний (например, `zap`, `cloud-lightning`). Никаких цветных эмодзи в интерфейсе бота, только строгий вектор. Дополнительно — [Weather Icons](https://erikflowers.github.io/weather-icons/) (SIL OFL) для специфичных метео-символов.
- **Тайлы карт:** **CartoDB Dark Matter** (No-labels или стандартный вариант). Провайдер предоставляет бесплатные тайлы на базе OSM (без необходимости API ключей для базового лимита). Это идеальный матово-темный сланцевый фон без цветных дорог и лесов, на котором неоновые молнии "горят".

## UNIQUE POSITIONING
- **Позиционирование:** Ваш личный тактический радар выживания.
- **Эмоциональный отклик:** Уверенность, собранность, технологичность. Интерфейс должен ощущаться не как развлекательное приложение о погоде, а как надежный авиационный прибор, спасающий жизнь.

## DESIGN LANGUAGE
### Цветовая система
Опираемся на выводы Шага 3 (WCAG AAA):
- **Background:** `#0C0D10` (Сланцево-черный). Гасит солнечные блики.
- **Warning (15km):** `#FFEA00` (Cyber Neon Yellow).
- **Critical (5km):** `#FF7575` (Neon Coral Red) / `#FF7B00` (Safety Neon Orange).
- **Halo Effect:** Все текстовые элементы на карте имеют обводку (stroke) цветом `#0C0D10` толщиной 2-3px.

### Типографика
- **Основной шрифт:** **JetBrains Mono** (SIL OFL, Google Fonts). Моноширинный шрифт ультимативно повышает скорость считывания меняющихся цифр (например, расстояния 15.2 км, 5.0 км) при тряске и на бегу.
- **Второстепенный шрифт:** **Inter** (SIL OFL). Гротеск с высокой читаемостью для длинных текстов и кнопок.

### Motion Character
- **Анимация:** Резкая, приборная, математическая. Никакого плавного "укачивающего" easing'а. Используем `ease-out` (быстрый старт, медленная остановка). 
- **Эффект вспышки:** При загрузке экстренного пуша экран может на долю секунды давать легкий желтый/коралловый flash (Opacity 0.1), имитирующий отблеск молнии.

### Сигнатурный визуальный паттерн
- **Радарная сетка (Radar Grid):** Темно-серые тонкие концентрические круги (opacity 10%) вокруг центра пользователя, обозначающие радиусы 5 км и 15 км. Придает приборный "милитари" вайб.
- **Изохронные контуры (SCIT):** Отрисовка движения шторма в виде жестких пунктирных векторов с моноширинными засечками времени.

## ANTI-PATTERNS LIST (Запрещенные приемы)
- ❌ **Пастельные и блеклые тона.** Сливаются на солнце.
- ❌ **Сложные градиенты без жестких границ.** Теряется контраст на бликующем стекле.
- ❌ **"Милые" или мультяшные иконки тучек.** Убивает серьезность тактического прибора.
- ❌ **Светлый фон (Light Mode) для карты.** Не дает нужного контраста для неоновых разрядов.
- ❌ **Тонкие начертания шрифтов (Light / Thin).** Нечитаемы на бегу. Только SemiBold и Bold.

## CROSS-PLATFORM LAYOUT COMPOSITION

### 1. Интерфейс Telegram-бота
- **Onboarding:** Минималистичный текстовый блок (Inter). Крупная кнопка "Активировать Радар" (Cyber Yellow плашка, черный текст Bold).
- **Экстренное сообщение:** Инвертированный блок. Если 5 км — текст пуша начинается с эмодзи 🚨, в TMA кнопка перекрашивается в Neon Coral Red.

### 2. Layout WebApp-компонента
- **Full-Screen Map:** Радар (MapLibre + CartoDB Dark Matter) растянут на 100% экрана, с учетом `safeAreaInset`.
- **Floating HUD:** Плавающие приборные кнопки (слои, центрирование) имеют фон `#0C0D10` с жесткой неоновой рамкой. Расположены в правом нижнем углу.
- **Инфо-панель:** В верхней части экрана — моноширинная плашка JetBrains Mono с дистанцией до грозы.

### 3. Карты-посты Threads (Статика для Imgur)
- **Размер:** Квадрат 1080x1080 px (идеально для соцсетей).
- **Композиция:**
  - Фон: Dark Matter OSM тайлы.
  - Центр: Гексагональный биннинг молний (Heatmap) или крупные точки.
  - Вектор движения шторма: Стрелка SCIT.
  - Водяной знак: В правом нижнем углу "Groza Bot [Radar]" моноширинным шрифтом.
  - Значения дистанции: Крупные цифры с черным Halo-эффектом.

### 4. Web Admin Dashboard
- **Сетка:** Приборная панель из плотных карточек (Dark UI).
- **Модули:** Центральная карта мира с тепловыми пятнами активности пользователей. Графики рассылки уведомлений (bar charts, line charts), выполненные в неоновых желто-оранжевых тонах на фоне `#0C0D10`.
