# ASSET REGISTRY: Personal Pocket Lightning Rod

Документ содержит верифицированный реестр графических и картографических ассетов, используемых в приложении для обеспечения автономности и соблюдения правила Zero-Cost.

## 1. ICONS BUNDLE (Локальные SVG Иконки)
Все иконки заимствованы из библиотеки **Lucide Icons** и зашиты прямо в конфигурационный файл `/config/assets_manifest.json` в виде чистых SVG-строк. Это устраняет зависимость от внешних CDN (например, unpkg) при отрисовке картинок на сервере Serv00.

| Иконка | Назначение | SVG Код (Пример) |
| :--- | :--- | :--- |
| `zap` | Маркер удара молнии | `<svg ...><polygon points="13 2 3 14 12 14 11 22 21 10 12 10 13 2"/></svg>` |
| `alert-triangle` | Желтый уровень предупреждения (15 км) | `<svg ...><path d="..."/><line .../></svg>` |
| `shield-alert` | Красный экстренный уровень (5 км) | `<svg ...><path d="..."/><line .../></svg>` |
| `map-pin` | Позиция пользователя (Live Location) | `<svg ...><path d="..."/><circle cx="12" cy="10" r="3"/></svg>` |

Обязательные атрибуты для всех иконок:
- `stroke="currentColor"` (Адаптация под системные токены)
- `stroke-width="2"`
- `fill="none"`

## 2. GIS TILE SERVERS (Картографические Тайлы)
Используются только полностью бесплатные эндпоинты, не требующие API-ключей.

### Primary Endpoint (CartoDB Dark Matter)
- **URL-шаблон:** `https://basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png`
- **Поддержка Retina:** `Да` (через параметр `{r}` = `@2x`).
- **Специфика:** Идеальный темный сланцевый фон (`#0C0D10`), соответствующий нашему Design Soul Document. Не требует токенов. Необходимо передавать корректный заголовок `User-Agent`.

### Failover Endpoint (OpenStreetMap Standard)
- **URL-шаблон:** `https://tile.openstreetmap.org/{z}/{x}/{y}.png`
- **Поддержка Retina:** Нет (рендерится базовый размер).
- **Специфика:** Резервный тайловый сервер на случай недоступности CartoDB. Светлая тема, которая на клиенте будет инвертирована через CSS-фильтры `filter: invert(90%) hue-rotate(180deg)` для сохранения Dark Mode.
